# 🛍️ Análise de Lojas - Projeto Data Science

Este projeto tem como objetivo analisar os dados de vendas de diferentes lojas, avaliando aspectos como:

- 📈 Faturamento
- ⭐ Avaliações dos clientes
- 🚚 Frete médio
- 🛒 Produtos mais vendidos
- 📊 Visualizações com gráficos

Com base nesses dados, será feita uma recomendação ao Senhor João sobre **qual loja é mais vantajosa para vender seus produtos**.

---

## 📁 Dados Utilizados

Os dados estão em formato CSV e contêm informações como:

- Nome da loja
- Categoria do produto
- Preço
- Avaliação
- Valor do frete
- Quantidade vendida

> 🔐 Os dados reais estão disponíveis na pasta `/dados` deste repositório ou integrados ao notebook.

---

## 🧪 Tecnologias Usadas

- Python 🐍
- Pandas (manipulação de dados)
- Matplotlib & Seaborn (visualizações)
- Google Colab / Jupyter Notebook
- Git & GitHub (versão e portfólio)

---

## 📊 Gráficos Criados

- Gráfico de barras: Faturamento por loja
- Gráfico de pizza: Distribuição por categoria
- Gráfico de dispersão: Avaliações x Preço

---

## ✅ Conclusão e Recomendação

> Após a análise, concluímos que a loja `XYZ` apresenta os melhores resultados em termos de faturamento, avaliações e custo-benefício. Portanto, recomendamos que o Senhor João concentre suas vendas nessa loja.
